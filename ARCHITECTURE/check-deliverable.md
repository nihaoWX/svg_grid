# 成品交付前检查脚本（`scripts/check_deliverable.py`）

> R8 起是**薄壳**（1 614 B：`sys.path` 注入 + 再导出 + `sys.exit(main())`），实现全在
> `scripts/deliverable_checks/` 包（`common / dead_band / outer_frame / summary / selftest / cli`）。
> 调用方（两份指南的 `05_checklist` C 节、`tests/{s22_repro,fig2_mixed}/compose_*.py`）**路径与 import 不变**。

## 1. 它为什么存在（单一判据）

这套判据曾**散在三处**（`05_checklist` 的 Python 片段 + 两个 `tests/*/compose_*.py`），
**三份、各自会误报**——"死白带误报"这一族因此在 `R3-F10 → R4-G2` **原地复发**。
现在：**判据只写在这里**，指南只写"跑这个脚本"。

用法：`~/.venv/bin/python tools/svg_grid/scripts/check_deliverable.py <成品.png> [--margin N] [--gap] [--label-band N]`
**退出码即结论**（`0` = 全过）。每条检查打印**它的判定依据**（可解释），**只有失败才给细节**，
**跳过一定打印并给原因**；`--selftest` 在合成数组上自证（每条检查既会通过也会触发 + 正负对照）。
脚本**可 import**（`check_dead_band` / `check_outer_frame` / `run_checks`）。

## 2. 两条检查

**检查 1｜死白带（修正后）**
先扣掉四边 `--margin` 与顶部 `--label-band`（字母带），把区域两端紧贴边的无墨连续行/列按
"**页边距 / 面板留白**"**豁免并打印 px**，**再只查完整的 `--band`（默认 200 px）窗口**（行带与列带都查）；
末尾不足一个窗口的余量**另判（豁免）**。多名/多列图有正常行/列间隔时加 `--gap` 豁免内部整块无墨带。

> 修正的两个**复发误报**：① **通栏面板的右页边距 > 200 px**（落进页边距豁免）；② **行间隔里坐着字母**
> （由 `--label-band` 扣掉）。**只统计完整窗口**这条也修掉了"末尾不足 200 px 的余量是白的就误报"。

**检查 2｜外框 2 px 墨迹 = 0**
图像最外 2 px 圈内的非背景像素数必须为 0。这是抓"**图例/长标签被右缘或左缘静默裁**"的
**唯一程序化手段**（被裁内容的 bbox 恰好贴着边缘，用"包围盒是否在画布内"判它**恒真**）。
**同一条里并报整图墨迹 bbox**（"内容落在哪"）。

- **「无裁切」由本条承担**；**输入侧更早由 W6 抓**（见 `warnings.md`）。
- **原"检查 2：内容未触画布边缘"已删**（2026-09-28 R6）：它用位图 bbox 判定 ⇒ **对位图输入恒真**、
  永远不会 FAIL，属**死重量**；其信息（墨迹 bbox）并进本条。

## 3. 它不覆盖什么（仍需按图自己量）

`panel` 包围盒两两不相交；文字/图例**两两无重叠**；字母墨宽 1.8–2.2 % W；字重。
——**多列图里长句越栏压叠时整幅处处有墨 ⇒ 死白带全绿也抓不到**，必须另做 bbox 两两检查。
细则见 skill 的 `01_canvas_layout.md`。

## 4. 与 vision 的分工

组好图后**必须**用 vision 工具打开**成品图**肉眼看一遍（版式平衡、死白、panel 被挤扁、字号可读）。
**程序化检查只是下限、不能替代**；两步都做。子代理会话 vision 不可用时，在报告里**明说**并交给
vision 可用的会话，**不得默默跳过、也不得谎称看过**。
