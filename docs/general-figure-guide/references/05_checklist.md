## C. 程序化验证（PIL / numpy）

```python
from PIL import Image
import numpy as np
from scipy import ndimage

a = np.asarray(Image.open(path).convert("L"))
H, W = a.shape

print("size", (W, H), "ink %.1f%%" % ((a < 250).mean() * 100))

# 1) 无死白带：每 200px 行带都要有墨
bands = [float((a[i:i+200] < 245).mean()) for i in range(0, H, 200)]
assert min(bands) > 0, f"empty band at {bands.index(0.0)*200}px"

# 2) 面板字母存在且大小/字重正确
#    （在预期字母位置取包围盒，量宽高与墨迹填充率）
lab, n = ndimage.label(sub < 100)          # sub = 字母所在区域
objs = ndimage.find_objects(lab)
# 宽 ≈ 1.8–2.2% W；填充率 ≈0.27（常规体）而非 ≈0.37（粗体）

# 3) 无裁切：内容包围盒不出画布
ys, xs = np.where(a < 250)
assert xs.min() >= 0 and xs.max() < W and ys.min() >= 0 and ys.max() < H

# 4) 面板包围盒互不相交（记录各 panel 的 bbox，两两检查重叠）
# 5) 文字/图例无重叠（记录各文字 bbox，两两检查）
```

### 视觉检查（vision，必做）——程序化验证不能替代

组好图后，**必须**用 vision 工具打开**成品图**肉眼判断（不看中间 panel）：版式是否平衡、有无显眼空白（大片死白 / 某 panel 明显压过同侪）、panel 是否被挤扁或缩得不可读、字换算到纸面尺寸后能否读。

- 上面「C. 程序化验证」只是**下限，不能替代**这一步——**两步都要做**。
- **标题在坐标轴上方是可以的**；禁止的 panel 内标题仅指落在 axes 数据区**内部**、可能与数据打架的标题。
- 查到空白/失衡：通常**把 panel 放大填满**（或重排行），而不是补更多白；**补充图不必守 A4 比例**，可裁画布贴合内容把页面填满。
- 子代理会话的 vision 可能不可用（无视输入固定返回一张无关图）：此时在报告里**明说**，把视觉检查交给 vision 可用的会话（主 agent）完成，**不得默默跳过，也不得谎称已做视觉检查**。
