# 交付前自查清单

逐条勾，任一不通过就回去改。能程序化验证的**不要靠肉眼**。

## A0. panel 来源（原生出图优先，机械可查）

判据在 `00_native_plots.md`；这里只留**能查**的三条。

- [ ] **每个 panel 都有一个来源标记**：或调用了分析包的**原生出图函数**（`# native: <包>::<函数>`），
  或脚本里有一行 `# native: none — <原因>`。`none` 的**原因必须含两处查证痕迹**：`tools/` 查了什么
  （无条目 / 命中哪个路径）+ 官方资料查了什么（版本或链接、`dir(...)` 结果），然后才是结论
  （为何仍需自绘，允许的理由只有 `00_native_plots.md` §3 那四类）。**只写"没有"不算**。
  ```bash
  grep -rn "# native:" <step>/figure_scripts/          # 应逐条出现，且与 panel 清单一一对应
  grep -rn "# native: none" <step>/figure_scripts/     # 逐条抽查：每一行都能回到那次查询（tools/ + 官方）
  ```
- [ ] **逐条对账**：`grep` 出来的 `# native:` 行数 == 该 step 的 panel 数（`figure_panels/` 里的 `.svg` 数），
  且每行要么是 `# native: <包>.<函数>`、要么是 `# native: none — <原因>`；`none` 的原因不许是"图省事/想自己配色"。
  ```bash
  grep -rho "# native: [^ ]*" <step>/figure_scripts/ | sort            # 每个 panel 一条，空行/缺行都可数出来
  ls <step>/figure_panels/*.svg | wc -l                               # 与上一条的行数对齐
  ```
- [ ] **视觉改动可列举、且没改图型**：原生出图之后做过的改动能写成一份清单——画布（尺寸/比例）、字号、
  配色、图例（是否外置）、panel 字母；清单里**不许出现**"换图型"的描述（把 UMAP 换成自己画的散点、
  把热图换成柱状、把火山图换成条形）。换句话说：`# native:` 指到的函数仍是这张图的**图型来源**。

## C. 程序化验证（**跑唯一脚本，别抄片段**）

判据**只写在一个地方**——`tools/svg_grid/scripts/check_deliverable.py`。组好图后跑它：

```bash
~/.venv/bin/python tools/svg_grid/scripts/check_deliverable.py <成品.png> [--margin 24] [--gap] [--label-band N]
```

- **退出码即结论**（`0` = 全过，非 0 = 有失败）；**每条检查一行**、**只有失败才给细节**、**跳过一定打印并给原因**；
  每条检查都会打印**它的判定依据**（检查 1：扣掉的四边 margin / 字母带 / 页边距豁免 / 末尾余量；检查 2：外框圈内像素数 + 整图墨迹 bbox），判据因此可解释。
- 两条检查：
  1. **死白带（修正后）**——先扣掉四边 `--margin` 与顶部 `--label-band`（字母带），把区域两端紧贴边的无墨连续行/列按"页边距 / 面板留白"豁免，**再只查完整的 `--band`（默认 200 px）窗口**（行带与列带都查）；末尾不足一个窗口的余量另判（豁免）。**多名/多列图有正常行/列间隔时加 `--gap`** 豁免内部整块无墨带。
     - 修正了两个复发误报：**通栏面板的右页边距 > 200 px**（落进页边距豁免）、**行间隔里坐着字母**（由 `--label-band` 扣掉）。
  2. **外框 2 px 墨迹 = 0**——图像最外 2 px 圈内的非背景像素数必须为 0；抓"图例/长标签被右缘/左缘静默裁"的**唯一程序化手段**（被裁内容的 bbox 恰好贴着边缘，拿"包围盒是否在画布内"判它抓不到）。**同一条里并报整图墨迹 bbox**（"内容落在哪"），于是一条检查同时给出"有没有触边"与"内容落在哪"。
     - **「无裁切」由本条承担**：位图输入的墨迹 bbox 必然落在画布内（对位图恒真），故**不再单列**"内容未触边 / 画布内 bbox"检查；**输入侧更早由 W6 抓**（见下一条）。
- `--margin` 按**该图自己的 margin 预算**给（默认 24 只是最低档）；字母在顶部占一条带时给 `--label-band`。
- 脚本**可 `import`**（判据是函数：`check_dead_band` / `check_outer_frame` / `run_checks`）；`--selftest` 在合成数组上自证（检查 1/2 既会通过也会触发；负向对照：真死带 ⇒ 检查 1 报、2 px 越界墨 ⇒ 检查 2 报；正向对照：干净图两条都过）。
- **读 `plot-grid` 的 stderr**：**W6（某输入内容墨迹越出它自己的画布）** 等告警一出现就按修法处理——该输入自身 PNG 会**静默丢字**，组图时若其所在侧 margin 为正会**贴着成品边缘现形**（详见 `02a`）。

脚本**不覆盖**、仍需按图自己量的：panel 包围盒互不相交、文字/图例两两无重叠、字母字号 1.8–2.2 % W、字重等（见 `01_canvas_layout.md`）。
> ⚠️ **死白带不能替代文字重叠检查**：多列图里长句越栏压叠时整幅处处有墨 ⇒ 死白带全绿。

### 视觉检查（vision，必做）——程序化验证不能替代

组好图后，**必须**用 vision 工具打开**成品图**肉眼判断（不看中间 panel）：版式是否平衡、有无显眼空白（大片死白 / 某 panel 明显压过同侪）、panel 是否被挤扁或缩得不可读、字换算到纸面尺寸后能否读。

- 上面「C. 程序化验证」只是**下限，不能替代**这一步——**两步都要做**。
- **标题在坐标轴上方是可以的**；禁止的 panel 内标题仅指落在 axes 数据区**内部**、可能与数据打架的标题。
- 查到空白/失衡：通常**把 panel 放大填满**（或重排行），而不是补更多白；**补充图不必守 A4 比例**，可裁画布贴合内容把页面填满。
- 子代理会话的 vision 可能不可用（无视输入固定返回一张无关图）：此时在报告里**明说**，把视觉检查交给 vision 可用的会话（主 agent）完成，**不得默默跳过，也不得谎称已做视觉检查**。
