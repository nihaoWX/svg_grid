# 画布、面板字母、字号与防重叠

## 1. 画布比例

| 图类型 | 要求 |
|---|---|
| **正图（main）** | **A4 比例**，600 dpi。竖版例：`4961 × 7016 px`（8.27 × 11.69 in）。横版则取 `7016 × 4961` |
| **补充图（supp）** | **可松懈**，不必强拉 A4。按内容自然比例出图即可 |

**理由**：正图要能单独占满期刊一页，统一 A4 让全篇版式一致；补充图数量多、内容零散，强拉 A4 反而留大片空白。

**排布原则**：面板按**内容量**分配画布面积；小字多的 panel（如逐基因热图）必须保留足够占比，否则缩放后基因名不可读。

## 2. 面板字母（A/B/C/D）

| 项 | 规则 |
|---|---|
| 位置 | 组图的**左上角外侧**（画布边缘与 panel 之间的留白处），**不画进 panel 内部** |
| 字体 | **默认 `Arial`**；`--label-fontfamily` 可改成任意族名或 **CSS 列表（回退链，第一个可用者生效）**。本指南的版面口径是 **serif、常规体、不加粗** ⇒ 传 `--label-fontfamily serif --label-fontface normal`。字体**只**从字体库目录读（用不到本机系统字体）：默认**数据根** `$HOME/svg_grid/fontlib`，`SVG_GRID_FONT_DIR` 或 `--font-dir <dir>` 换成别的目录；`--list-fonts` 列出库里实际可用的族；换机器跑一次 `fontlib/setup.sh`（幂等，默认就装进数据根，把本机 Arial / Times New Roman 复制进来）；要的族不在库里会在 stderr 出 W8（非致命，会回退到别的族、字宽与换行随之改变），按它给的修法补字体或改族名。库里一个字体都没有而要出 PNG/AVIF 或要加字母 ⇒ **非零退出**（不会静默出白图） |
| 大小 | 占**画布宽度约 1.8–2.2 %** |
| 内容 | 只放字母本身。**组图阶段不新增任何 panel 内文字**；源面板自带的标题若位于坐标轴**上方**则保留（见 §3），落在数据区内部或图外的脚注/来源标注则不要（说明文字放 md 图注） |


> 字重判据：**拿同一个字母自己对比**——把它在常规体与粗体下各渲一次、量墨迹填充率，取更接近的那个。`0.27（常规）/ 0.37（粗体）` 是 **`A`** 的实测值；**不要**拿这两个数字去套别的字母——填充率强烈依赖字形（常规体的 `B`/`D`/`E` 可达 0.36–0.43，按 0.37 会被误判成粗体）。

> **提醒**：`label_fontface = "bold"` 会渲成粗体且偏大——要求是 **serif 不加粗、占比小**。改字号后要**同步重算纵向布局**，保证各 panel 高度之和仍精确等于画布高度（不留死区、不重叠）。

## 3. 字号

- 整体**偏小**，以**已发表的同类图**为参照，而不是"把画布填满"。
- 换算要落到**纸面 pt**：`纸面pt = 标称pt × (panel在纸上的宽度) / (绘图画布宽度)`。
  - 例：1800 px 绘图 @300 dpi = 6 in 宽，缩到正图 3 列中的一列 ≈ 2.57 in → 字号乘 0.43。原本 9 pt 只剩 ~3.9 pt（低于期刊 5–6 pt 下限）。
  - 修正办法二选一或并用：**放大源图字号** + **改画布纵横比使其填满格子**（避免被高度限制而缩得更小）。
    **注意**：字号放大**不得超过几何缩放比例 `s`**（`s = 格子尺寸 ÷ 面板画布尺寸`；`k = s` 是唯一可证安全的档位）——`s` 的后果、核对方法与逐面板归一化的做法见 `02a_svg_grid_assembly.md` 的「让面板落在它的尺度上」一节。
- panel 内允许的文字：坐标轴标签、刻度、图例条目、数据标签、行列名、化学结构的原子符号，以及**位于坐标轴上方**的标题（源面板自带的标题属此类，保留）。
- 禁止：**落在坐标轴数据区内部**的标题（会与数据打架）、图外的脚注/来源说明、`(A)` `(B)` 这类自标字母（字母由组图层统一加），以及**在组图阶段新增**的任何 panel 内文字。

## 4. 图例

- 放**坐标轴右侧外侧**，不放坐标轴内部。
- **窄格必须把"右外距"（图例）与"左外距"（y 轴刻度标签）一起算进画布**：`bbox_to_anchor` 只给图例**起点**，宽度由文字决定，matplotlib **不会把图例缩进画布**——条目稍长就被画布右缘**静默裁掉**；对称地，**y 轴刻度标签不得触左缘**，长标签会被左缘静默切（两者同族，退出码 0、stderr 无提示，`svg_grid convert` 也照收）。估法：可用宽 ≈ `最长条目字符数 × 字号 × em/字符` + `handlelength × 字号` + `handletextpad × 字号`；据此把 axes 右边界压到 `1 − 可用宽/画布宽 − 余量`。格子越窄越紧张（2 列时单格常只有 ~2180 px = 3.63 in）。
  - **em/字符 的适用范围**：`0.5 em/字符` **只适合粗估**；**DejaVu Serif 混排英文实测 ≈ 0.57 em/字符**（按 0.5 估会偏小、照样裁）。CJK 的换算见 §5。
  - **反算式**：$axes\_left \ge (\text{最长标签宽} + tick\_pad + 余量) / 画布宽$；右缘同理 $axes\_right \le 1 − (\text{图例可用宽} + 余量) / 画布宽$。
  - **「2 px 外框墨迹检查」是抓这类静默裁切的唯一程序化手段，不能省**——只看"内容包围盒是否在画布内"抓不到它（被裁内容恰好贴着边缘、bbox 也在画布内，故那条对位图恒真、已不单列）。
- 越界用两道检查兜底：① 程序化——跑 `tools/svg_grid/scripts/check_deliverable.py`（其「外框 2 px 墨迹 = 0」即这条；见 `05_checklist.md` C 节）② vision 目视——被裁的是**文字尾部**，只看 bbox 容易被"内容确实到了边缘"蒙混过去。
- 图内图例极易与数据点、残基标签、刻度文字重叠（真实教训：某 panel 的图注框压在数据上）。
- 图例字号与图内正文同级（同样偏小）。

## 5. 防重叠（必须程序化检查）

- 长 y 轴标签/刻度文字要预留边距，或改用**共享轴**（多 facet 共用一个 y 轴，只最左列显示刻度）。
- 检查项：
  1. 各 panel 的像素包围盒**互不相交**（留出 gap）
  2. 所有文字包围盒在画布内（无裁切）
  3. 文字之间无重叠
  4. 图例框与数据区域无重叠
  5. 无死白带：**扣掉四边 margin 与字母带后，只统计完整的 200 px 窗口**（行带与列带都查），末尾不足 200 px 的余量另判（豁免）——它常常就是边距，按"必须有墨"要求会误报。**跑 `tools/svg_grid/scripts/check_deliverable.py` 即这条**（见 `05_checklist.md` C 节）
- **多列图先划列、再放字**：给每列定好 x 区间，所有文字按列宽反算可容纳字数（CJK：`字号 pt ≈ 单位 pt`，1 数据单位 ≈ 5.28 pt @4400 px/100 unit），超出就换行。长句**横向越过列边界压到相邻列**时整幅处处有墨 ⇒ **死白带检查全绿也抓不到**；必须另做**文字 bbox 两两不相交**检查（`check_deliverable.py` 不覆盖这条，须按图自己量），且成品图的 vision 目视是硬步骤。
- **示意图的"沟槽"同时是标注位与连线位**：优先把标注放**节点框内**（同色 token + 图例给颜色映射），沟槽只留连线；确需在沟槽标注时，其 y 要**高于该处全部扇入扇出的箭头包络**（只按自己那根算会被邻组的箭头穿过）。
- 用脚本算，不靠肉眼看（跑 `tools/svg_grid/scripts/check_deliverable.py`，用法见 `references/05_checklist.md` C 节）。

## 6. 常见排布范式（本项目已验证可用）

| 结构 | 用法 |
|---|---|
| 3×3 网格 | 9 个同构小图（如 9 个靶点的结合模式） |
| 2×3 facet 网格 | 6 个组内比较小图 |
| 上下通栏堆叠 | 大表（热图）在上、结构条带在下，各占整幅宽 |
| 左列小图 + 右列大图 | 左列放配体结构/图例类小 panel，右列放大图 |

> 排布一旦定版（用户认可），后续图沿用同一套骨架，保持全篇一致。

**正图 A4 竖版（`4961 × 7016`）的格尺寸速查**（`margin = gap = 150`）：多列时**格宽不再等于画布宽**，须按两轴分别反推 `n_col·CW + (n_col−1)·gap + 2·margin = 4961`、`n_row·CH + (n_row−1)·gap + 2·margin = 7016`：

| 排布 | 格宽 CW | 格高 CH |
|---|---|---|
| 1 列 × 3 行 | 4661 | 2138.67 |
| 2 列 × 3 行 | 2255.5 | 2138.67 |
| 2 列 × 2 行 | 2255.5 | 3283 |
| 3 列 × 3 行 | 1453.67 | 2138.67 |

**两轴必须各自满足 A4**：只按横向方程定格宽、再用面板纵横比去推格高 ⇒ 纵向总高 ≠ 画布高，组图端要么留一条 ~600 px 竖白带（比例不再是 A4）、要么给 `--height` 强拉 ⇒ 触发"格子被拉伸"告警。

**补充图「2+1 通栏」算例**（`W = 4448, gap = 40, margin = 24`，本项目 S39/S40 实测）：行 1 两格各 `(4448 − 2·24 − 40) / 2 = 2180`；行 2 通栏（1 列）= `4448 − 2·24 = 4400`。**通栏格宽不是两列格宽**（`4400 ≠ 2180`）——通栏面板必须按 `4400/600` in 出图、两列面板按 `2180/600` in，否则组图时被两轴独立缩放（`s ≠ 1`、触发 W1、纸面字号漂移）。补充图不必强拉 A4，这类"2+1"版式**没有现成速查值**，必须按 `n_col·CW + (n_col−1)·gap + 2·margin = W` **逐行自己算**。

> 通栏行 + `--labels C` 时，**"自动字母带"只长该行的 `top` 边距、不动左右**（S39/S40：`top` 24 → 126.227，左右仍是 24）⇒ **不会**把该行格宽从 4400 压小，`s = 1`、无 W1。故这里只需核对：输出里 **`data-panel-box` 的 `width` 是否仍等于预算格宽**（本例 `width = 4400`）——单列行的字母带只吃垂直空间，不必预留横向余量。
