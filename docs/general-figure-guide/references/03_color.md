# 配色

## 原则

1. **现代期刊风**——避免通篇灰冷、暗沉的"老气"感（如整幅深蓝/灰底）。
2. **colorblind-safe**——色盲友好是硬要求，不用红绿对撞表达对立类别。
3. **低饱和互补**——同一张图内类别色饱和度接近、明度接近，视觉权重均衡。
4. **单色连续**用于连续量（打分、表达量、距离）：单色调由浅到深，不要用彩虹色（rainbow/jet）。
5. **语义一致**——同一变量在全篇用同一颜色（如化合物 A 永远是同一个青绿）。跨图保持映射一致。

## 可用色板（已验证）

**类别色（4 类，colorblind-safe）**

| 类别 | Hex | 说明 |
|---|---|---|
| A | `#5FA8A0` | muted teal |
| B | `#E0907E` | soft salmon |
| C | `#CFA15A` | warm ochre |
| D | `#9E9AC8` | muted lavender |

色盲友好备选（Okabe–Ito 系）：
```
#0072B2  #E69F00  #009E73  #CC79A7  #56B4E9  #D55E00  #F0E442  #999999
```

**连续色（单色由浅到深）**，用于打分/表达量热图：
```
#2E6B66 → #5FA8A0 → #A9D0C8 → #D9E9E5 → #F1F6F5
```
（深 = 值强的方向；具体哪端为"强"由量纲决定，例如对接打分越负越深。）

**发散色**（正负/上下调）：蓝–白–红家族，中点为白，避免用彩虹。

**元素/结构色（化学图）**
```
C 黑/深灰   O #E53935   N #3B6FB5   S #E6A800   P #FF7F00
金属：Zn 银灰 #8A8D93   Fe 橙 #E69F00
辅因子碳架：HEM 砖红 #B54434   NADP/NDP 天蓝 #56B4E9
```

## 反面清单

- ❌ 彩虹/jet 色板表示连续量
- ❌ 只用红/绿区分两组
- ❌ 同图内类别色饱和度过差悬殊（一个荧光色 + 三个灰）
- ❌ 全图灰冷暗沉（"老气"）
- ❌ 同一化合物在不同 panel 换色

## 验证

- 灰度化后各颜色仍可区分（打印友好）
- 用 colorblind 模拟器过一遍（红绿色盲下仍可区分）
- 色值直接写进脚本常量，不要"随手挑色"
